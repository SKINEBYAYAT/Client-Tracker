Appointment Conflict Detection

When a user saves or edits a visit:

1. Load every appointment scheduled on the same date.
2. Compare the selected appointment time with every existing appointment.
3. If another appointment exists within 2 hours (before or after), prevent saving.
4. Show a clear validation error explaining why.

Example:

Existing appointment:

* Sarah — 12:30 PM

Trying to save:

* Ali — 1:30 PM

Result:

Do NOT save.

Display something similar to:

“Time unavailable.

Sarah already has an appointment at 12:30 PM.

Appointments must be at least 2 hours apart.”

If the nearest appointment is 2 hours or more away, allow saving.

Examples:

12:30 → 1:30 ❌ Reject

12:30 → 2:00 ✅ Allow

9:00 → 10:45 ❌ Reject

9:00 → 11:00 ✅ Allow

The comparison should use:

absolute time difference < 2 hours = conflict

absolute time difference >= 2 hours = allowed
